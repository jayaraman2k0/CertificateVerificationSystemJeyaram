# SmartCertificateSystem - Console Demo

This console application demonstrates a Smart Certificate Verification System using OOP principles in C# (.NET 6).

Structure:
- Models: User, Student, Admin, Employer, Certificate, Transcript, Course
- Services: DatabaseManager (simulated CRUD)
- Utilities: FileManager (file read/write)
- Data: SampleData (seed)

Run:
- Open in Visual Studio 2022/2026, set as startup project, build and run.

Features:
- Inheritance, polymorphism, method overloading
- File handling (StreamReader/Writer, FileStream)
- LINQ queries and sorting
- Exception handling
- Simulated DB CRUD operations
